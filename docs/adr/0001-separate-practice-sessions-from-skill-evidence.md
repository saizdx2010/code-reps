# 0001: Separate practice sessions from skill evidence

Status: Superseded — practice sessions retired (769a139)

Daily practice needs to acknowledge saved effort and reflection even when a rep remains unfinished. Record ended sessions separately from completed attempts and independence or retention evidence, rather than making session endings count toward those assessments. This adds a learner-data contract, but preserves honest assessment and prevents daily participation from silently changing recall scheduling or skill states.

Practice sessions were later removed from the interface; a completed attempt is now the record of practice. Existing `sessions:v1` records still validate and import from backups. See [Maintaining](../MAINTAINING.md#retired-practice-session-records).
