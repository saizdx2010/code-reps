# Code Reps

Code Reps supports authored coding practice and learner reflection, with evidence of independent work and later recall.

## Language

**Daily practice session**:
An explicitly started period of work on one rep with accompanying learner reflection. Starting practice again creates a new session, while crossing midnight alone does not.
_Avoid_: Daily quota, course

**Session ended**:
The learner has saved their work and reflection and chosen to stop the session. The rep may still be incomplete.
_Avoid_: Rep completed, skill retained

**Goal path**:
The path the learner has chosen as their current learning focus. A suggested default becomes the goal only when the learner chooses it.
_Avoid_: Browsing selection, assigned course

**Practice record**:
A record of an ended session, including its reflection and connection to the learner's work. It does not by itself establish rep completion or skill evidence.
_Avoid_: Completed attempt, mastery evidence

**Path**:
An ordered sequence of reps toward a learning goal. It is the main view of the curriculum.
_Avoid_: Skill journey, session

**Due recall**:
A scheduled opportunity to apply a previously practised skill after a gap. It has first priority in the daily practice recommendation.
_Avoid_: Overdue assignment, mastery test
